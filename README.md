# IC-4301 — Bases de Datos I

Proyectos del curso Bases de Datos I (IC-4301), enfocados en el diseño de sistemas de información y la persistencia de datos. El repositorio reúne una aplicación para registrar biodiversidad y un proyecto de investigación sobre bases de datos orientadas a objetos.

## Proyecto I (Registro de biodiversidad)

El proyecto consistía en desarrollar una versión simplificada de una plataforma como iNaturalist para registrar y consultar observaciones de la biodiversidad de Costa Rica. Los usuarios podían aportar observaciones de organismos con su ubicación, fecha, imagen y notas, asociándolas a una especie o a un nivel más general de la clasificación taxonómica cuando no fuera posible identificarla con precisión. Otros miembros de la comunidad podían proponer identificaciones para contribuir al reconocimiento de los organismos observados.

El trabajo abarcaba el diseño de una base de datos relacional normalizada y una aplicación en Java con Spring Boot y Hibernate para gestionar las observaciones y sus identificaciones. También se solicitaban consultas e informes que permitieran visualizar los registros, sus datos generales y la jerarquía taxonómica asociada. El propósito era relacionar el modelado de datos, las restricciones de integridad y las operaciones de la aplicación con las necesidades de un sistema de información.

## Proyecto de investigación (Gestión de biblioteca con db4o)

El proyecto de investigación exploraba el uso de db4o como base de datos orientada a objetos mediante una aplicación de gestión de biblioteca en Java. El sistema reúne libros, usuarios, categorías y préstamos, permitiendo administrar el catálogo, consultar libros y su disponibilidad, registrar préstamos y devoluciones, y revisar el historial de préstamos desde una interfaz gráfica.

La propuesta buscaba estudiar cómo almacenar y consultar directamente los objetos de la aplicación y sus relaciones mediante un modelo de persistencia orientado a objetos. Además del desarrollo del sistema, el trabajo contemplaba explicar el modelo de datos y los componentes construidos, presentar una demostración de la aplicación y analizar los resultados y las conclusiones de la investigación.
